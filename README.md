# functions-journey · מסע הפונקציות

קורס אינטראקטיבי בעברית לטאבלט: גרפים של פונקציות קוויות, קצב השתנות, חקירת טבלה ומשוואות עם סוגריים.
שיעורים מוקראים עם אנימציות, תרגול עם משוב מיידי, דפי החוברת, ומבחן עם ציון והסבר מלא לכל שאלה.

נבנה ב‑React + Vite.

## הפעלה

```bash
npm install
npm run dev
```

- במחשב: http://localhost:5180
- בטאבלט (באותה רשת Wi‑Fi): `http://<כתובת ה‑IP של המחשב>:5180` — הכתובת מודפסת בטרמינל בשורת `Network`.

## קול (ElevenLabs)

ההקלטות של השיעורים ושל דפי החוברת כבר נמצאות ב‑`public/tts`, ולכן הן מתנגנות גם בלי מפתח.

כדי שגם ההסברים של תרגילים אקראיים יוקלטו (ברגע שפותחים אותם), צריך קובץ `config.env` בתיקיית הפרויקט:

```
ELEVEN_LABS_API_KEY=המפתח_שלך
```

הקובץ לא עולה ל‑git, והמפתח נשאר במחשב — הטאבלט מקבל רק קובצי שמע.
בלי מפתח, משפטים שלא הוקלטו מושמעים בקול העברי של המכשיר.

| פקודה | מה היא עושה |
| --- | --- |
| `npm run voices -- --dry` | סופרת כמה משפטים חסרים וכמה תווים הם יעלו (בלי עלות) |
| `npm run voices` | מקליטה את כל המשפטים הקבועים שחסרים |

הקולות מוגדרים ב‑`src/lib/tts.shared.js`. אחרי שינוי טקסט של שיעור או החלפת קול מריצים שוב `npm run voices`.

## שמירת התקדמות

ההתקדמות (כוכבים, שיעורים שהושלמו, ציוני מבחנים, הגדרות) נשמרת בקובץ אחד במחשב: `data/progress.json`.
כל מכשיר שפותח את הקורס מהשרת קורא את אותו קובץ, כך שאפשר להפסיק בטאבלט ולהמשיך ממכשיר אחר.
אין משתמשים ואין סיסמאות: זה קורס לתלמיד אחד ברשת הביתית.

## אירוח באינטרנט (למשל Render)

| שדה | ערך |
| --- | --- |
| Build Command | `npm install && npm run build` |
| Start Command | `npm start` |
| משתנה סביבה `ELEVEN_LABS_API_KEY` | המפתח (במקום הקובץ `config.env`) |
| משתנה סביבה `COURSE_DATA_DIR` | רק אם מחובר דיסק קבוע: נתיב הדיסק, למשל `/var/data` |
| משתנה סביבה `TTS_DAILY_CHARS` | לא חובה: תקרת תווים יומית להקלטה לפי דרישה (ברירת מחדל 20000) |

בלי דיסק קבוע, קובץ ההתקדמות נמחק בכל הפעלה מחדש של השרת. ההתקדמות עדיין שמורה בכל מכשיר,
והמכשיר הראשון שמתחבר ממלא את השרת מחדש — אבל מכשיר אחר יראה אותה רק אחרי זה.

| --- | --- |

| `scripts/generate-voices.mjs` | הקלטה מראש של כל המשפטים הקבועים |
